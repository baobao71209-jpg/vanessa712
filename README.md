# 宝宝的小日子

可自定义宝宝昵称的中文家庭手账，包含餐食照片、奶量、食谱周历、采购清单、阿姨考勤、计薪结算和成长记录。

## GitHub Pages 发布

1. 在 GitHub 新建公开仓库，例如 `baby-little-days`。
2. 将本目录的 `index.html`、`app.js`、`style.css`、`scrapbook.css` 和 `.nojekyll` 放在仓库根目录，不要上传 ZIP 文件本身。
3. 打开仓库 Settings → Pages，Source 选择 Deploy from a branch，选择 main 分支和 / (root)，点击 Save。
4. 等待 GitHub 发布成功，使用 Pages 页面显示的链接。

不需要安装依赖或构建。网页不依赖外部字体、图片或脚本服务。

## 首次使用

- 家庭设置：修改宝宝昵称和工资配置。
- 工资结算：填写上次发薪日，从次日起累计计薪天数。
- 普通出勤和带薪假计 1 天，春节出勤默认计 3 天，其他节日出勤规则待用户确认。
- 默认每 26 个计薪日结算 4800 元，超额计薪日结转。工作小时数独立记录，不自动换算为计薪日。

## 数据迁移与备份

数据仅保存在当前浏览器的 localStorage，不会上传 GitHub。分享网页链接不会分享家庭记录，但同一设备同一浏览器使用的是同一份账本。

网址变化后，旧网址的数据不会自动出现。先到旧网站导出 JSON 备份，再到新网站的家庭设置导入。不要把包含照片、考勤或工资的 JSON 备份上传到公开仓库。

清除浏览器数据或更换设备前，请导出备份。本站不提供跨设备同步或网页关闭时的推送提醒。

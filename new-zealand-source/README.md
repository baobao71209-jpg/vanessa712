# 新西兰旅行工作台

2026 年 10 月 31 日至 11 月 11 日的家庭旅行手册，无需登录。

已构建的网站位于仓库 `new-zealand/`，源代码位于 `new-zealand-source/`。保留仓库原有首页。GitHub Pages 从 main 分支根目录发布时可直接访问旅行站子目录。

## 功能

- 新西兰日期对应的今日卡，出发前显示准备卡，返程后显示回顾。
- 12 天行程、酒店导航、景点实景照片、美食与特产。
- 景点观察提示，12 天打卡、旅行小记与文本导出。
- 常用中英文短句、大字展示、浏览器朗读和在线翻译。
- 本地行程助手，不调用付费 AI，不含密钥，不冒充实时联网问答。

打卡和小记只保存在当前浏览器，清除浏览器数据可能丢失，请定期导出。照片、地图、天气、在线翻译需要相应外部服务可访问，不保证离线可用。照片许可和来源见页面底部。

## 更新

在源代码目录安装 Node.js 24 和 pnpm 11，运行 `pnpm install --frozen-lockfile`，再运行 `pnpm build`。将 dist 中的文件更新到 `new-zealand/`，保留根目录原有文件。无需服务器或腾讯云。

航班与酒店资料来自旧行程，出行前以本次预订为准。
